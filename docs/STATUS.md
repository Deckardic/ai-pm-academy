# Состояние проекта

Документ для продолжения работы: что сделано и что осталось. Требования — в [`PRD.md`](PRD.md),
программа курса — в [`PROGRAM.md`](PROGRAM.md), соглашения по коду — в [`../AGENTS.md`](../AGENTS.md),
команды и деплой — в [`../README.md`](../README.md).

## Сделано

- Платформа на Next.js 16 (FSD, Cache Components): каталог, уровни, модули, уроки, тесты модулей,
  практические задания с эталонными решениями, итоговые экзамены, сертификаты с публичной
  проверкой, тест на уровень, кабинет, библиотеки промптов и шаблонов, глоссарий, юридические
  страницы, cookie-баннер, SEO/GEO (sitemap, robots, llms.txt, JSON-LD).
- Контент уровней Junior и Middle полностью опубликован: 24 модуля, 99 уроков, тесты всех модулей,
  экзамены (137 и 125 вопросов), тест на уровень (48 вопросов), 102 промпта, 26 шаблонов,
  202 термина глоссария.
- Проверки: `pnpm check` (ESLint, Steiger, типы, валидация контента, юнит-тесты) и `pnpm test:e2e`
  (сценарии пользователя, сертификаты Junior и Middle, WCAG 2.2 AA в светлой и тёмной темах).
  Lighthouse на ключевых страницах: производительность 89–97, остальное — 100.

## Осталось

### Перед запуском

1. **152-ФЗ.** Заменить заглушки `[наименование / ФИО]`, `[ИНН]`, `[адрес]`, `[email]` в
   `content/legal/soglasie.mdx` и `content/legal/politika-konfidencialnosti.mdx`; подать уведомление
   в Роскомнадзор; показать юристу политику, согласие и урок `m11-02` (ссылки на consultant.ru в нём
   не проверялись вручную).
2. **Деплой в Yandex Cloud** по разделу README «Деплой»: Managed PostgreSQL, Container Registry +
   Serverless Containers, Lockbox (секреты из `.env.example`), Postbox, Cloud CDN, домен, OAuth-ключи
   Яндекс ID и VK ID, Яндекс Метрика, Яндекс Вебмастер. После — замерить реальные Core Web Vitals.
3. **Вычитка контента.** Прогнать `pnpm content:review` (нужны переменные `CONTENT_REVIEW_*`) и
   выборочно проверить вручную уроки с расчётами (EVM, Монте-Карло, метрики потока), правовые уроки
   и вопросы экзаменов.

### Потом

4. Дизайн-проход.
5. Уровень Senior: спецификации модулей в `content/course/senior/`, затем генерация и валидация.
