## Задание

Соберите библиотеку промптов для своей команды или для команды учебного портала для дилеров.

1. Выберите 10 повторяющихся задач команды.
2. Для каждой оформите промпт по стандарту.
3. Минимум два промпта сделайте цепочками, два — с примерами.
4. Для трёх ключевых промптов подготовьте тестовые входы.
5. Опишите правила библиотеки.
6. Посчитайте экономию времени для трёх промптов.

## Как использовать ИИ

Попросите ассистента покритиковать каждый промпт и предложить граничные случаи для тестов. Прогоните
тесты сами и сравните с ожидаемым результатом.
