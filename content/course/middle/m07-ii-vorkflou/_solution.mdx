## Пример хорошего решения (фрагмент)

**Промпт: «Сводка противоречий в требованиях»** · версия 1.2 · владелец — аналитик · 12.09

- **Назначение:** найти противоречия между требованиями разных отделов.
- **Когда не использовать:** если требований меньше десяти — быстрее вручную.
- **Цепочка:** 1) извлечь требования с цитатами → проверка PM; 2) сгруппировать по темам;
  3) найти противоречия с цитатами с обеих сторон → проверка PM; 4) вопросы к отделам.
- **Переменные:** `{{протоколы}}` — обезличенные протоколы с датами; `{{отделы}}` — список ролей.
- **Что проверить:** у каждого требования есть цитата; нет требований без источника; учтены более
  поздние решения; оговорки на месте.
- **Данные:** без имён, названий дилеров и цен; только в корпоративный ассистент.
- **Тесты:** 3 набора протоколов с заранее известными противоречиями.

**Правила библиотеки:** раздел в базе знаний; изменение — через комментарий и ревью второго
человека с прогоном тестов; правило «сначала библиотека»; раз в месяц — разбор обратной связи.
