## Пример хорошего решения (фрагмент)

**Ограничения:** бюджет траншами; подрядчик по интеграции с фиксированным договором; оферта для
дилеров требует согласования юристов; требования к порталу неясны, дилеры разные.

**Схема:** Исследование (4 недели) → ворота 1 → Пилот для 5 дилеров (8 недель, спринты по 2 недели)
→ ворота 2 → Полная версия (12 недель, спринты) → ворота 3 → Поэтапный запуск.

| Элемент | Ограничение | Зачем |
|---|---|---|
| Ворота 1–3 | Бюджет траншами | Решение о следующем транше по данным |
| Спринты с демонстрациями пилотным дилерам | Неясные требования | Ранняя обратная связь |
| Вехи подрядчика и общий план вех | Фиксированный договор | Синхронизация без изменения договора на каждом спринте |
| Веха «Оферта согласована» до ворот 3, юрист на обзорах раз в месяц | Юридическое согласование | Нет сюрпризов перед запуском |
| Процедура изменений для работ подрядчика | Фиксированный договор | Изменения оценены и согласованы |

**Встречи:** планирование и обзор спринта (команда, Product Owner, пилотные дилеры на обзоре);
созвон с подрядчиком по вторникам (синхронизация по вехам); статус для финансового директора раз в
две недели письмом; ворота — два часа, решение на месте.

**Пересмотр:** на ретро каждые две недели; обязательно — после каждых ворот.

**ИИ-оппонент** спросил, что будет, если подрядчик сорвёт веху перед воротами 2. Добавлен
вариант: ворота проводятся на заглушке интеграции, риск отражается в рекомендации.
