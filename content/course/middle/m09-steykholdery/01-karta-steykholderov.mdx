Портал для дилеров поддержали генеральный директор и коммерческий директор. Проект идёт хорошо, пока
на контрольной точке финансовый директор не заявляет, что интеграция с учётной системой «рискованна
для закрытия квартала», и предлагает отложить запуск на полгода. PM знал, что финансовый директор —
важный стейкхолдер. Но не знал, что тот против, и не знал, что главный бухгалтер, с которым никто не
разговаривал, уже месяц убеждает его в рисках. Карта стейкхолдеров была, а понимания позиций — нет.

## Матрица власти и интереса

Базовая карта — матрица по двум осям: насколько человек может повлиять на проект (власть) и
насколько ему важен результат (интерес).

| | Низкий интерес | Высокий интерес |
|---|---|---|
| **Высокая власть** | Держать удовлетворёнными | Управлять плотно |
| **Низкая власть** | Наблюдать | Держать в курсе |

На уровне Middle важно помнить об ограничениях матрицы: она статична и ничего не говорит о том,
**за** или **против** человек. Высокая власть и высокий интерес бывают у главного сторонника и у
главного противника проекта.

## Текущая и желаемая вовлечённость

Полезно добавить оценку вовлечённости. Распространённая шкала:

- **Не осведомлён** — не знает о проекте и его влиянии.
- **Сопротивляется** — знает и против изменений.
- **Нейтрален** — знает, но не поддерживает и не мешает.
- **Поддерживает** — знает и поддерживает.
- **Лидирует** — активно продвигает проект.

Для каждого ключевого стейкхолдера отметьте две позиции: **текущую** (Т) и **желаемую** (Ж) — какая
нужна для успеха проекта.

| Стейкхолдер | Не осв. | Сопр. | Нейтр. | Подд. | Лид. |
|---|---|---|---|---|---|
| Коммерческий директор | | | | | Т, Ж |
| Финансовый директор | | Т | | Ж | |
| Главный бухгалтер | | Т | Ж | | |
| Руководитель логистики | Т | | | Ж | |
| Менеджеры отдела продаж | | | Т | Ж | |

Разрыв между Т и Ж — это и есть план работы со стейкхолдерами. Не всем нужно быть лидерами:
главному бухгалтеру достаточно перейти от сопротивления к нейтральной позиции.

<Callout type="important" title="Карта — рабочий документ PM, а не публичный">
Оценки вроде «сопротивляется» могут задеть людей. Храните карту с позициями там, где её видят только
те, кому нужно, а публичной делайте версию с ролями и способами коммуникации.
</Callout>

## Скрытые влиятельные люди

Формальная власть — не единственная. На решения влияют:

- **советники** руководителей — главный бухгалтер при финансовом директоре;
- **эксперты**, к мнению которых прислушиваются, — опытный менеджер по продажам, которого считают
  «голосом дилеров»;
- **владельцы ресурсов** — руководитель, от которого зависят люди для проекта;
- **ключевые пользователи** — если крупнейший дилер против портала, это станет аргументом.

Как их найти:

- спрашивайте: «С кем вы советуетесь по таким вопросам?», «Чьё мнение здесь важно?»;
- смотрите, кто приходит на встречи вместе с руководителями и кого цитируют;
- замечайте, чьи возражения повторяют другие.

## Обновление карты

Позиции меняются: проект переходит в новую фазу, меняются руководители, появляются новые
стейкхолдеры, первые результаты меняют мнения. Карту стоит пересматривать:

- на каждой контрольной точке;
- при смене ключевых людей;
- когда кто-то неожиданно меняет позицию;
- перед важными решениями и запуском.

<Callout type="mistake" title="Составить карту на старте и забыть">
Карта, составленная на инициации, через три месяца описывает другой проект. Самые неприятные
сюрпризы приходят от людей, чья позиция изменилась незаметно для PM.
</Callout>

## Практика

Составьте карту стейкхолдеров для проекта с конфликтующими интересами — портала для дилеров, где
продажи хотят быстрый запуск, финансы боятся рисков интеграции, логистика не хочет, чтобы дилеры
видели остатки склада. Для 6–8 стейкхолдеров укажите власть, интерес, текущую и желаемую
вовлечённость, скрытых влиятельных людей и первые шаги по сокращению разрывов.

<KeyTakeaways>
- Матрица власти и интереса не показывает, за или против человек; нужна оценка вовлечённости.
- Текущая и желаемая вовлечённость определяют план работы; не всем нужно быть лидерами.
- Скрытые влиятельные люди — советники, эксперты, владельцы ресурсов, ключевые пользователи.
- Карта с позициями — рабочий документ PM, публичная версия — без оценок.
- Карту обновляют на контрольных точках, при смене людей и неожиданных изменениях позиций.
</KeyTakeaways>
