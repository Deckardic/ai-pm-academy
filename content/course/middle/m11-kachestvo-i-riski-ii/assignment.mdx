## Задание

Подготовьте для своей команды или команды портала для дилеров комплект правил:

1. Чек-листы проверки для четырёх типов задач.
2. Правила глубины проверки: что полностью, что выборочно.
3. Таблица данных и инструментов.
4. Порядок действий при ошибке и при утечке.
5. Правило раскрытия использования ИИ.

## Как использовать ИИ

Попросите ассистента предложить пункты чек-листов и типичные ошибки для каждого типа задач. Сверьте
правила по данным с политикой компании — у неё приоритет.
