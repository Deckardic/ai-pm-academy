## Задание

Соберите бэклог для B2B-портала заказов для дилеров — или для своего проекта.

1. Выявите требования: используйте протоколы, интервью или учебные вводные.
2. Запишите 15–20 пользовательских историй для разных ролей.
3. Для каждой — критерии приёмки «Дано — Когда — Тогда».
4. Отметьте нефункциональные требования.
5. Приоритизируйте бэклог по RICE или WSJF, покажите оценки и обоснования.
6. Разберите запрос на изменение: «добавить персональные скидки для топ-20 дилеров в текущий
   релиз».

## Как использовать ИИ

Используйте цепочку «извлечь — проверить — найти противоречия» и промпты «Извлечение требований из
протокола» и «Оценка запроса на изменение». Для каждого требования держите источник. Оценки для
приоритизации ставьте сами.
