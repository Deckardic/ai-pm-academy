## Задание

Спроектируйте автоматизированный воркфлоу для своей команды или для учебного портала — например,
еженедельный сбор статусов от подрядчика со сводкой для PM.

1. Обоснуйте выбор задачи.
2. Нарисуйте схему: триггеры, условия, действия, участие ИИ и человека.
3. Опишите путь данных и доступы.
4. Опишите обработку ошибок и мониторинг.
5. Оцените экономию времени с учётом поддержки.
6. Заполните описание автоматизации для реестра.

## Как использовать ИИ

Попросите ассистента найти слабые места схемы: что будет при сбое каждого шага, где данные могут
уйти не туда. Проверьте схему по чек-листу безопасности из урока.
