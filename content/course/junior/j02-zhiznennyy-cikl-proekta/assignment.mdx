## Задание

Учебный проект: клиника запускает онлайн-запись к врачам на сайте, личный кабинет пациента и
напоминания о визите. Срок — три месяца, команда — три человека и подрядчик по интеграции с
расписанием врачей.

1. Разложите проект по пяти фазам: инициация, планирование, исполнение, мониторинг и контроль,
   закрытие. Для каждой фазы запишите 2–3 ключевых результата и кто их принимает.
2. Расставьте на временной шкале не меньше пяти вех. Формулируйте их как свершившийся факт.
3. Выберите три вехи, которые будут контрольными точками. Для каждой укажите, кто принимает
   решение, какие решения возможны и какая информация нужна.
4. Сформулируйте 3–5 измеримых критериев успеха: для проекта и для продукта. У каждого — мера,
   срок и кто его проверит.
5. Оформите всё одной таблицей или схемой.

## Как использовать ИИ

Попросите ассистента составить черновик чек-листа результатов для каждой фазы и проверить ваши
критерии успеха на измеримость. Проверьте, что модель учла специфику медицинских данных, и не
берите из ответа целевые числа — их согласуют с заказчиком.
