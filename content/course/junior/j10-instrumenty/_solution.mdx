## Пример хорошего решения

**Колонки и правила перехода**

| Колонка | Правило входа |
|---|---|
| Бэклог | Любая идея или задача проекта |
| Готово к работе | Есть описание результата, оценка и ответственный |
| В работе | Ответственный начал работу; не больше двух задач на человека |
| Ждёт внешних | Указано, кого ждём и с какого числа |
| Проверка | Результат можно показать; указан проверяющий |
| Готово | Результат принят заказчиком задачи |

**Типы задач:** задача, ошибка, согласование, веха.

**Обязательные поля:** ответственный, срок, описание результата; для ошибок — шаги
воспроизведения; для «Ждёт внешних» — кого ждём.

**Задачи на доске (фрагмент):** «Интеграция с расписанием» — «Ждёт внешних» (подрядчик, с 3 октября);
«Текст напоминаний» — «Проверка» (проверяет руководитель регистратуры); «Согласие на
напоминания» — «Готово к работе» (PM, до 20 октября); «Запуск в двух отделениях» — веха в бэклоге.

**Связь с базой знаний:** в описании каждой вехи — ссылка на раздел плана; задачи, созданные по
итогам встреч, ссылаются на протокол; решения фиксируются в журнале решений, а в задаче — ссылка
на запись.

**Чистка:** по пятницам 15 минут — закрыть неактуальное, разобрать задачи без движения больше двух
недель, обновить сроки.

**ИИ:** встроенная функция разбила «Напоминания» на 8 подзадач. Две лишние (SMS-шлюз и push-
уведомления — вне границ проекта), не хватало согласования текста с юристом.
