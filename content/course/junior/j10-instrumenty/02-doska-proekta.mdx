Доска проекта онлайн-записи: колонки «Сделать», «В работе», «Готово». В «В работе» — 23 задачи,
часть из них там с сентября. Одни ждут подрядчика, другие — проверки, третьи давно никто не
трогал. Посмотрев на доску, нельзя понять, что происходит в проекте. Доска есть, но она ничего не
показывает.

## Колонки отражают реальные этапы

Колонки — это шаги, которые задача проходит от идеи до результата. Если в колонке «В работе»
прячутся ожидание, проверка и согласование, доска не показывает, где застревает работа.

Как спроектировать колонки:

1. Возьмите пять-семь недавних задач и восстановите, какие этапы они проходили на самом деле.
2. Выделите этапы, где работа ждёт: согласование, проверка, внешняя сторона.
3. Не дробите слишком мелко: пять-семь колонок обычно достаточно.

Пример для проекта онлайн-записи:

| Колонка | Что означает |
|---|---|
| Бэклог | Задачи, которые, возможно, сделаем |
| Готово к работе | Описаны, оценены, можно брать |
| В работе | Кто-то активно делает |
| Ждёт внешних | Ждём подрядчика, юриста, заказчика |
| Проверка | Тестирование или согласование результата |
| Готово | Принято, соответствует критериям готовности |

<Callout type="important" title="Колонка ожидания — самая полезная">
Отдельная колонка для задач, которые ждут внешнюю сторону, сразу показывает, сколько работы
заблокировано и кем. Это готовый материал для разговора с подрядчиком или эскалации.
</Callout>

## Типы задач и обязательные поля

**Типы задач** помогают различать работу по смыслу. Для небольшого проекта достаточно трёх-четырёх:

- **Задача** — обычная работа с результатом;
- **Ошибка** — что-то работает не так, как должно;
- **Вопрос или согласование** — нужно решение или ответ;
- **Веха** — ключевой результат проекта.

**Обязательные поля** — минимум, без которого задачу нельзя взять в работу:

- **Ответственный** — один человек;
- **Срок** — когда нужен результат;
- **Описание результата** — что должно получиться и как проверить, что готово.

Для ошибок полезно поле «как воспроизвести», для задач с внешней зависимостью — «кого ждём».

<Callout type="mistake" title="Задача из одного заголовка">
«Сделать напоминания» — через неделю никто не вспомнит, что имелось в виду: какой текст, за сколько
до визита, через какой канал. Описание результата пишется при создании задачи, а не потом.
</Callout>

## Правила перехода между колонками

Правила отвечают на вопрос: когда задачу можно передвинуть в следующую колонку? Без них статус
субъективен: для одного «Готово» — это «код написан», для другого — «пациенты могут записаться».

Примеры правил:

- **В «Готово к работе»** — есть описание результата, оценка и ответственный.
- **В «В работе»** — ответственный начал работу; у одного человека не больше двух задач в этой
  колонке.
- **В «Проверку»** — результат можно показать; указано, кто проверяет.
- **В «Готово»** — результат проверен и принят тем, кто его заказывал.

## Как не превратить доску в кладбище задач

Признаки кладбища: сотни задач в бэклоге, которые никто не будет делать; задачи в «В работе» без
движения неделями; задачи без ответственных.

Что помогает:

- **Еженедельная чистка.** 15 минут: закрыть неактуальные задачи, обновить сроки, разобрать
  зависшие.
- **Правило давности.** Задача без движения больше двух недель — повод спросить, актуальна ли
  она.
- **Ограничение бэклога.** Если задачу не возьмут в работу в ближайшие месяцы, её можно закрыть
  или вынести в список идей.
- **Работа с доской на встречах.** Синхронизация команды проходит по доске: так она остаётся
  актуальной.

## Практика

Настройте учебную доску проекта онлайн-записи в любом доступном трекере или в таблице:

1. Колонки по реальным этапам работы, включая колонку ожидания.
2. Три-четыре типа задач.
3. Обязательные поля.
4. Правила перехода для каждой колонки.
5. Заведите 10–12 задач проекта и распределите их по колонкам.

<KeyTakeaways>
- Колонки доски отражают реальные этапы работы, включая этапы ожидания.
- Три-четыре типа задач и обязательные поля: ответственный, срок, описание результата.
- Правила перехода делают статус однозначным.
- Колонка ожидания показывает, сколько работы заблокировано и кем.
- Еженедельная чистка и работа с доской на встречах не дают ей превратиться в кладбище.
</KeyTakeaways>
