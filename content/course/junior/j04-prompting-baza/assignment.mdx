## Задание

Соберите личную библиотеку из десяти промптов для повторяющихся задач.

1. Выпишите задачи, которые повторяются у вас хотя бы раз в месяц: статус-отчёт, протокол,
   письмо о проблеме, повестка встречи, список рисков, вопросы стейкхолдеру и т. д.
2. Для каждой задачи напишите промпт по структуре из пяти элементов.
3. Вынесите меняющиеся данные в переменные.
4. Запустите каждый промпт на реальной или учебной задаче. Сохраните пример результата.
5. Для каждого промпта запишите, что нужно проверять в ответе.

## Как использовать ИИ

Попросите ассистента покритиковать каждый промпт: чего не хватает, где модель может додумать
лишнее. Можно взять за основу промпты из библиотеки курса, но обязательно адаптируйте их под себя.
